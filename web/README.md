# OrgFlow web app

The console for OrgFlow: a Next.js app exported as static files and served by Firebase Hosting.
See the [main README](../README.md) for what OrgFlow does, how to run it and how to deploy it.

```bash
cp .env.example .env.local   # then fill in the API address and, optionally, Firebase
npm install
npm run dev                  # http://localhost:3000
```
